Clinic Matcher

Review sources spell the same clinic many ways: Hangul or English, PS or Plastic Surgery, road name first or building number first. This page maps each scraped record to one canonical clinic and decides whether it is safe to merge.

AUTO merges only when the building and the name (or the floor) agree. REVIEW goes to a person, because a wrong merge puts one clinic's reviews on another clinic's page. NEW is a clinic not in the directory yet.

One record per line: name | address. The canonical list is 16 clinics copied from gangnambeautyguide.com (name and address only). The sample records below are synthetic test inputs, not real reviews.
