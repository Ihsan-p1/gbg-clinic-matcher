Which clinic is this review about?

Korean review sources spell the same clinic many ways: Hangul or English, PS or Plastic Surgery, road first or building number first. Merging the wrong pair puts one clinic's reviews on another clinic's page, and trust is the product. This page decides, record by record, whether a merge is safe.

Scraped records

One per line: name | address. Results update as you type.

How it decides

  1. Normalise the address: Hangul road and district names to romanised form, then a key of road + building number. Floors are read separately (12F, 12층, 7th floor, 12F~15F).
  2. Normalise the name: drop Plastic Surgery, PS, 성형외과, 의원, punctuation.
  3. AUTO only when the building matches and the name or the floor confirms it.
  4. REVIEW when signals disagree or only the name matches. A building can house several clinics, and a name can belong to a branch.
  5. NEW when neither the building nor the name is in the directory.

Rules, not an LLM: every decision can be explained and audited. A model is worth adding later for the REVIEW pile only.

Step 2: the same review, posted twice

Naver Cafe posts get copied to blogs with an emoji or a "ㅎㅎ" added. Counting both inflates a clinic's rating. Reviews are compared on 3-character shingles, which works for Hangul without a tokenizer; pairs above 50% overlap collapse into one review.

Limit: a translated copy shares no characters with its original, so the English line below stays separate. Catching it needs multilingual embeddings, which is the next step, not this one.
